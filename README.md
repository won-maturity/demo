# WON하는 만기

우리WON뱅킹 스타일의 아이디어 경진대회 데모입니다.

```sh
npm ci
npm run dev
```

앱에서 **홈 → WON하는 만기**로 들어가세요. 현행 앱 캡처를 기준으로 하단 탭을 **상품 · 자산·소비 · 홈 · 주식 · 혜택** 순서로 배치했습니다. 상단 AI 아이콘으로 만기 상담을 열 수 있으며, 대화 입력과 선택지는 기존 시연 규칙을 사용합니다. 스크롤바를 숨기고 내용 스크롤은 유지했습니다. 처음 열면 추천 시연 고객으로 시작합니다. **전체 → 시연 고객 및 엔진 패널**에서 다른 고객과 엔진 표시를 선택할 수 있습니다.

**홈 → 알림 → 바탕화면 알림 시연**에서 스마트폰 바탕화면을 열 수 있습니다. 잠시 뒤 나타나는 만기 알림을 누르면 WON하는 만기 요약이 열립니다. 이 장면은 브라우저 알림 권한 없이 재생됩니다.

**홈 → 알림 → 시연 알림 보내기**를 누르고 브라우저 알림을 허용하세요. 기기 알림을 누르면 WON하는 만기가 열립니다. 로컬호스트 또는 HTTPS에서 동작하는 시연용 알림이며, 서버 예약 발송 없이 버튼으로 호출합니다. 브라우저가 기기 알림을 지원하지 않으면 앱 안의 만기 알림을 누르세요.

만기 상담은 AI 소개 → 모의 은행 조회 → 은행 조회 정보 카드 → 확인 대화 순서로 시작합니다. 기존 투자성향 진단과 포트폴리오 분석을 읽기 전용 모의 도구로 가져옵니다. 김재원은 적극투자형으로 공식 계열사 상품인 우리투자증권 RP형 CMA와 우리자산운용 WON 미국S&P500(444490)을 비교할 수 있고, 소원은 안정형, 양대건은 투자 의사 없음으로 예금만 비교합니다. 앱에서 새 성향 진단을 완료시키지 않습니다. 실제 은행 API와 LLM은 연결되지 않은 시연입니다. 상품몰 → 우리금융그룹 상품 또는 선택지 비교 하단에서 공식 계열사 상품과 원문 링크를 확인할 수 있습니다. 실제 상품 정보의 근거와 노출 규칙은 [계열사 상품 자료](docs/affiliate-products.md)에 정리했습니다. **전체 → 시연 고객 및 엔진 패널 → 조회 실패 시연**에서 다음 조회를 1회 실패시켜 재시도를 확인할 수 있습니다. 엔진 패널에는 도구 상태와 반환값이 표시됩니다. 채팅 제목 오른쪽 아이콘으로 AI갤러리를 열 수 있으며, 닫으면 대화와 입력 중 문장을 이어갑니다.
