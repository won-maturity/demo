# 목적별 만기 자금 분리 시연

## 정하늘 · 페르소나 E

- 42세, 자녀 학비와 이사를 준비하는 부모
- 안정형, 투자 의사 없음, 예금·현금 100%의 모의 기존 포트폴리오
- 만기 원금 30,000,000원, 만기일 2026.11.21
- 학비 15,000,000원: 2027.05.20
- 이사비 15,000,000원: “내년 봄쯤”으로 시작, 고객이 2027.03.31을 선택

## 재생 순서

전체 메뉴 → 시연 고객 및 엔진 패널 → 정하늘 → “이 시나리오로 상담 시작”을 누른다.

1. 모의 도구에서 만기 계좌와 기존 성향·포트폴리오 정보를 가져온다. 시연 발화는 입력창에 준비되며 자동 전송되지 않는다.
2. 입력된 “3천만 원 중 반은 내년 5월 20일 아이 학비, 나머지는 이사 가서 내년 봄쯤 쓸 것 같아요”를 보낸다.
3. AI 해석 카드에서 학비·이사 각 1,500만 원을 확인한다. AI가 이사 자금을 쓸 “봄쯤”이 3월 말인지 묻는다.
4. 이사 항목에서 “3월 말”을 선택한다. 이 단계만으로 상품 비교가 시작되지 않는다.
5. “이대로 맞아요”를 누르면 목적별 분리 계획을 만들고, 선택지 비교에서 2027.05.20 / 2027.03.31 만기의 우리 SUPER 정기예금 두 건을 보여 준다. 재예치는 계속 기본 선택이다.

첨부 자료의 5월 20일 확정값을 재현하기 위해 이 시연 발화에는 일자까지 명시했다. “내년 5월”만 말하면 월 범위만 추출하고 일자를 다시 확인한다. 고객이 말하지 않은 날짜를 AI가 확정하지 않는다. 모호한 이사 일정 역시 고객이 선택하기 전까지 미확정이다.

상품 결정은 기존 규칙 엔진이 수행하고, 해석기는 목적·금액·시기를 추출한다. 계좌·금리·분석은 시연 데이터이며 실제 가입은 실행하지 않는다.
