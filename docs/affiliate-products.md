# 공식 계열사 상품

정보 확인일: 2026-11-11. 개인별 성향·잔액·포트폴리오 조회는 기존 모의 데이터이며, 아래 상품명과 설명은 실제 계열사 공식 자료를 사용한다. 실시간 판매 조건·거래 가능 여부를 조회하는 연동은 아니다.

RP 설명서 심사필: 제2026-014호(2026.02.23~2027.02.22). 종금형 CMA Note와 RP형 CMA는 별개 상품이다. [공식 상품몰](https://securities.wooriib.com/hpko/fngo/FNGO_MAIN.jsp)에 우리WON CMA Note는 신규가입 중단으로 표시되어 신규 비교 대상으로 사용하지 않았다.

## 노출 및 진행

- 상품몰 → 우리금융그룹 상품, 만기 선택지 비교 → 우리금융 계열사 상품 살펴보기: 두 공식 상품의 정보와 원문 링크를 제공한다.
- 김재원의 1~3년/3년 이상 자금: 재예치를 기본 선택으로 두고 RP형 CMA(대기자금 운용)와 WON 미국S&P500(주식 투자)을 비교한다. 최대 3개 선택지 제한을 유지한다.
- 안정추구형: 주식 ETF 대신 RP형 CMA만 투자 비교 대상으로 허용한다.
- 양대건의 투자 거절, 소원의 안정형, 미진단, 단기·시기 미정 자금은 기존 투자 제외 규칙을 유지한다. 제외 이유를 비교 화면에 표시한다.
- 공식 상품에 가상의 과거 수익률, 손실 한도 또는 수수료를 붙이지 않는다. 기존 예금 금리와 계좌 정보는 데모 예시로 구분한다.
- 이해도 확인·숙려·최종 승인은 데모의 자체 시연 규칙이다. 계열사의 실제 의무 절차라고 주장하지 않는다. 실제 가입·매매는 수행하지 않는다.
